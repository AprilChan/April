# 陈林君个人作品集设计契约

## 1. 页面架构结论

- 页面类型：单页作品集，包含“项目”和“简历”两个互斥视图。

- 路由：`/` 默认展示项目；Tab 状态同步到 URL hash：`#projects`、`#resume`。

- 参考语言：借鉴 gionatannese.com 的全屏主视觉、居中悬浮导航、极简排版和指针驱动反馈，不复制其品牌资产。

- 规范降级：ve-o-design 的 `reference/` 与 `check/` 目录缺失，本项目采用通用作品集与无障碍校验规则。

## 2. 页面整体架构

- 固定顶部：个人标识、项目/简历 Tab、联系入口。

- 项目视图：

  - 首屏身份信息与动态作品舞台。

  - 项目索引，展示 14 个 PDF 或长图项目。

  - 点击项目卡片打开站内项目阅读器；PDF 所有页面纵向连续展示，长图按原始内容比例展示，均通过自然滚动浏览，不提供下载或外部打开入口。

- 简历视图：

  - 姓名、职位、联系方式和个人总结。

- 按简历原文倒序展示字节跳动、脉脉、百度、匙悟科技工作经历。

  - 展示教育背景，不展示独立的核心能力模块。

  - 提供简历 PDF 下载入口。

  - 首屏采用单行职位标题，下方左侧集中姓名、总结、操作入口，右侧展示个人头像；不展示经验数字表格。

  - 工作经历与教育经历使用一致的左侧纵向标题、右侧内容列表结构。

  - 工作经历不展示序号；公司、职位与就职时间在桌面端保持同一行。

  - 教育经历的学校、专业、学位与时间在桌面端保持同一行。

  - 工作与教育条目均使用“单行元信息头 + 下方职责列表”的统一结构，移动端空间不足时自然换行。

  - 联系入口同时提供邮箱与电话号码，电话号码使用可拨打的 `tel:` 链接。

- 页脚：邮箱和当前年份。

## 3. 视觉与布局

- 色彩：白色背景、黑色正文、酸性绿色强调；避免单一蓝紫或米色主题。

- 排版：无衬线正文 + 编辑感衬线展示字；标题不随 viewport 直接线性缩放。

- 网格：桌面 12 列，移动端单列；内容最大宽度 1440px。

- 卡片：圆角不超过 8px，项目封面使用原 PDF 首页，通过 Canvas 渲染。

- 响应式：`< 760px` 时顶部导航压缩、首屏改为纵向结构、项目列表单列。

- 窄屏首屏的作品配图进入正常内容流，位于身份文案之前，不与姓名或英文名使用重叠定位。

- 窄屏首屏的作品配图与姓名之间保留明确的视觉间距，需覆盖卡片旋转后超出容器的视觉边界。

- 项目固定排序：Xpert 专家社区、标注模板体验优化、精标工艺模板优化、工作经验分享、模型动态调用通用能力、代码SFT提效提质、脉脉 6.0 产品架构升级、脉脉 5.0 交互升级、脉脉 NPS 用户研究、同事圈产品演进、内容发布体验演进、图片与视频发布体验、NCAA 赛事周边体验研究、Collaborative Methods。

- 首屏项目插图固定展示项目列表第一项，即 Xpert 专家社区。

- 首屏项目插图不展示竖排项目数量标签；前景封面必须完全填充卡片，不允许露出容器背景或底部白条。深色封面使用 1px 低对比度浅色描边，与背后的黑色卡片建立边界。

- 项目首屏与列表预览统一加载静态轻量封面图，不读取完整 PDF；完整 PDF 及 PDF.js 仅在用户打开项目详情后按需加载。

- 简历职位标题保持单行并使用较小字号；移动端通过断点缩放保证不溢出。

- 用户提供的头像作为首屏内容资产，使用裁切比例固定的 `<img>` 展示。

- 个人总结与操作按钮组使用同一内容宽度，最大宽度为 `600px`；邮箱入口直接展示完整邮箱地址。

- 桌面端个人信息与右侧头像之间使用加大的双栏间距。

## 4. 模块与组件映射

- 顶部导航：原生 `header/nav/button/a`，Tab 使用 `aria-selected`。

- 动态主视觉：CSS 变量 + Pointer Events 驱动，不依赖滚动劫持。

- 项目封面：PDF 和长图均使用预生成的轻量 `<img>` 封面；失败或加载中显示文字封面。

- 项目列表：语义化 `article`，支持键盘聚焦和明确操作按钮。

- 简历经历列表：语义化 `section/article/header/time/ol/ul`。

- 项目阅读：PDF 使用 `pdfjs-dist` Canvas 阅读器，以纵向页面列表连续展示并按可视区域懒渲染；长图按比例置于同一滚动阅读区。工具栏仅保留文档信息、页数或长图类型与关闭操作。

- PDF 阅读器通过 Portal 挂载到 `document.body`，避免页面动画容器的 `transform` 影响固定定位与完整显示。

## 5. 核心交互闭环

- Tab：点击切换内容、更新 hash、焦点和选中态保持一致。

- 项目悬停：封面轻微位移、标题与索引产生对比反馈。

- 项目打开：点击卡片或“站内浏览”打开全屏阅读器，不离开作品集。

- 项目浏览：在阅读器正文区域自然向下滚动连续查看全部 PDF 页面或完整长图，无需逐页点击切换。

- 下载简历：直接下载 `resume.pdf`。

- 动效降级：系统开启减少动态效果时，禁用跟随和位移动画。

## 6. 状态与边界

- 项目加载中：封面显示项目序号与加载提示；PDF 阅读器各页保留稳定比例占位并在进入可视区域后完成渲染；长图保持稳定容器并等待图片加载。

- 性能：首屏高优先级加载 Xpert 封面，其余封面使用浏览器懒加载；PDF.js 拆分为异步代码块，首屏不下载解析库和 PDF 正文。

- PDF 加载失败：保留项目文字信息并在阅读器内显示失败状态。

- 小屏：不依赖 hover；封面始终可见。

- Safari：英文姓名使用显式两行结构，不依赖 `ch` 单位或字体测量结果换行。

- JavaScript 关闭：保留基础文案与 PDF 链接。

## 7. Mapping Gate

- 页面框架命中：单页作品集双视图。

- 模块命中：导航、项目舞台、项目索引、简历、页脚。

- 组件命中：原生语义组件、Canvas、PDF.js。

- 核心功能命中：站内浏览项目 PDF、查看简历、下载简历。

- 交互闭环命中：Tab、项目访问、下载、响应式和动效降级。

## 8. 验收约束

- 桌面端与移动端首屏无重叠、无横向滚动。

- 项目 PDF 首页、长图封面及阅读器内容均能正常渲染，项目区无下载入口。

- Tab 可用键盘操作，焦点样式清晰。

- 控制台无运行时错误，生产构建通过。
